# 单词随行 · 四六级浏览助手

一个 Manifest V3 浏览器扩展：在浏览网页时自动展示四六级单词，切换页面时弹出英文名人名言，帮助利用碎片时间背单词。

## 功能

- 浏览任意网页时，右下角显示单词浮窗：单词、音标、词性、中文释义、例句和中文翻译。
- 按「认识 / 再学」按钮或快捷键操作，按间隔记忆安排复习。
- 错词本：点「再学」或测验答错的单词会自动收进错词本；学习页「错词本」标签可查看错词、错误次数和最近出错时间，点「掌握」可移除，也可一键清空。
- 每日错题温习：按 5 分钟、30 分钟、12 小时、1 天、2 天、4 天、7 天、15 天的间隔安排错词复习，答对逐步延长间隔，答错回到短间隔。
- 错词本支持导出和导入 JSON；错词导出文件也可以作为自定义词库导入。
- 多词库学习：内置词库和多个自定义词库都可通过复选框任意组合，学习、测验和网页浮窗使用同一组选择。
- 自定义词库：每次导入 CSV 或 JSON 前填写词库名称，词库会独立保存，可分别导出或删除。
- 复习调试台：可将插件内学习日期推进指定天数，现场验证第 1、2、4、7、15 天的复习变化；不会修改电脑系统时间，恢复时会还原调试前的学习进度快照。
- 每次打开新页面时弹出英文名人名言（含中文翻译），可关闭或调整弹出间隔。
- 浮窗可拖拽、可隐藏，隐藏后右下角出现悬浮按钮，点击即可重新打开。
- 插件弹窗包含：学习卡片、今日进度统计、四选一测验、设置（词库范围 / 名言开关 / 间隔）。
- 独立学习页：点击扩展弹窗的「打开学习页」会在新标签页打开全屏学习页，包含大号单词卡片、今日进度、四选一测验、每日错题温习和词库范围切换；支持 `1` 认识、`2` 再学、`空格` 换词快捷键。
- 扩展弹窗的「查看错词本」按钮会直接打开学习页的错词本视图。
- 内置 3 万余条词库：CET4、CET6、考研、托福、SAT，可自由切换范围；学习进度、错词本和自定义词库保存在浏览器本地。
- 词库由 `wordbank/` 目录统一管理，每个范围一个 CSV，可直接用 Excel/VS Code 增删词条，运行 `build_wordbank.py` 重新生成。

## 安装到浏览器

1. 打开 Chrome 或 Edge，访问 `chrome://extensions`（Edge 为 `edge://extensions`）。
2. 打开右上角「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择本目录 `browser-extension`。
4. 打开任意网页即可看到右下角单词浮窗。

## 快捷键

| 快捷键 | 功能 |
| --- | --- |
| `Alt+Shift+W` | 显示 / 隐藏单词浮窗 |

浮窗内「认识 / 再学」按钮可点击，浮窗头部可按住拖拽移动位置。

## 文件结构

- `manifest.json`：Manifest V3 配置
- `content.js` / `content.css`：网页内浮窗与名言弹窗
- `background.js`：后台服务，处理快捷键与名言消息
- `quotes.js`：名言数据
- `words.js`：由 `wordbank/*.csv` 生成的扩展运行时词库（自动生成，勿手改）
- `popup.html` / `popup.js` / `popup.css`：扩展弹窗（学习 / 测验 / 设置）
- `learn.html` / `learn.js` / `learn.css`：独立学习页
- `ww-common.js`：共享数据格式、唯一键和间隔复习工具

## 常见问题

- 浮窗没有出现：确认扩展已启用，并刷新已打开的网页。
- 名言不弹：设置里打开「切页名言」，并保持名言间隔设置合理。
- 数据丢失：学习进度存储在 `chrome.storage.local`，卸载扩展会清除。
- 想加词或加范围：编辑 `wordbank/` 下的 CSV，然后运行 `python build_wordbank.py` 并重新加载扩展。
- 想临时增加个人词汇：打开学习页底部，填写词库名称后点击「导入词库」。CSV 表头使用 `word,phonetic,pos,meaning,example,example_zh`，也可导入对应 JSON。
- 错词备份：在「错词本」页面点击「导出错词」，以后可用「导入错词」恢复。
- 导入错词中不属于内置范围的词，会自动建立一个独立的“导入错题”词库并加入当前选择。
- 演示遗忘曲线：先把一个词加入错词本，再在学习页「高级设置」中打开「复习调试台」，依次推进天数，观察“每日错题温习”的到期数量；演示结束点击「恢复真实时间」。
