# WordEveryWhere · 四六级浏览助手

WordEveryWhere 是一个面向 Microsoft Edge/Chrome 的四六级背词浏览器插件。用户浏览网页时可以看到低打扰的单词浮窗，切换页面时会弹出英文名言；完整学习页提供四选一、每日间隔复习、错词本和自定义词库。

当前主线是浏览器插件版，源码位于 [browser-extension](browser-extension/)。学习记录保存在浏览器本地，不需要账号、服务器或数据库。

## 插件功能

- 浏览网页时显示单词、音标、词性、释义和例句，可记录“认识 / 再学”。
- 切换网页时显示英文名言及中文翻译，可在设置中关闭或调整间隔。
- 独立学习页包含普通背词、四选一、每日复习、错词本和今日统计。
- 每日复习按“到期单词复习 → 四选一 → 词语补全”依次进行，错过的复习会保留到后续日期。
- 内置 CET4、CET6、考研、托福、SAT 词库，支持导入命名词库、导入导出错题和多词库组合。
- 学习数据使用 `chrome.storage.local` 保存；高级设置中的复习调试台可以模拟日期推进。

## 安装与运行

1. 打开 Microsoft Edge，访问 `edge://extensions`。
2. 打开右上角“开发人员模式”。
3. 点击“加载解压缩的扩展”，选择本项目的 `browser-extension` 文件夹。
4. 打开任意网页即可看到单词浮窗，点击扩展图标可以进入学习页。
5. 修改代码后回到扩展管理页点击“重新加载”，再刷新网页。

词库源文件位于 `wordbank/`。修改 CSV 后，在项目根目录运行 `python build_wordbank.py`，再重新加载扩展。

## 目录说明

- `browser-extension/`：Manifest V3 插件源码。
- `wordbank/`：可维护的 CET4、CET6、考研、托福、SAT CSV 词库。
- `build_wordbank.py`：把 CSV 生成浏览器运行时词库的脚本。
- `软件开发文档_单词随行.docx`：按课程模板填写的项目开发文档。
- `小学期项目问卷_单词随行.docx`：项目问卷。

## 历史文件

早期桌面宠物原型、旧素材和外部词库来源统一存放在 `temp/`，不参与浏览器插件运行，上传或发布插件时无需包含该目录。
